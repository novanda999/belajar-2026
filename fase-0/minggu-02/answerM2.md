jawaban 
1. git sendiri ini sendiri setelah aku baca penjelasan mu berupa adalah sebuah program pencatat riwayat perubahan kode yang berjalan secara lokal di komputer masing-masing penggunanya , sedangkan git hub merupakan sebuah website untuk menyimpan file hasil kerja kita yang local ini untuk di upload secara online sebagai sarana kolaborative atau pun dibagikan secara public

2. commit ini jika aku menelaah penejlasanmu berati commit ini seperti meyimpan kondisi file kita yang sudah kita edit aku rasa sperti file temporaray dan file temporary kita baru akan kita upload saat kita melakukan git push , pesan commit sendiri itu kita harus lakukan jelas karena saat kita melakukan perbuahan file setiap catatan itu akan membantu kita melakukan trouble shotting atau melakukan segala perubahan yang ada , hal ini sangat membantu nantinya saat kita melakukan proses toruble shotting , dan saat kita melakukan me manage bebrbagai macam project kita tidak akan kebingungan karena kita dapat menngecek dari setiap catatan yang ada

3. git add menurutku adalah sebuah fungsi dimana kita melakukan proes penambhaan atau proses perubahan terhadap file yang sudah dibuat atau yang sebelumnya ada ke stagging kita sebelum kita melakukan commit karena dengan git add kita menandai file mana saja yang akan kita commit , jika kita commit terlebih dahulu sebelum git add , maka tidak akan ada perubahan yang terjadi 

4. branch sendiri selama aku mempelajari nya merupakan sebuah rak atau tempat tambahan yang masihsaling menyambung dalam rak utama kita , jika kita melakukan git commit atau edit sebagainya itu tidak akan langsung melakukan perubahan di main dan itu lebih aman saat mengerjakan sesuatu yang bersifat expirimental , agar tidak terjadi error yang diinginkan , dan kenapa tidak langsung kerja di main menurutku berkerja langsung di main , membuat perkajaan kita lebih beresiko karena kita langsung melakukan perbuahan yang bersifat langsung dan hal itu membuat kita tidak mempunyai backup atau versi stable dari software yang kita buat 

5. git push memnurutku melakukan proses uplaoad sendangakan git pull adalah proses download
